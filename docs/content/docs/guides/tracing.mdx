---
title: Trace requests
description: Continue or start a W3C trace for each request in an Air app, pass the trace to services that you call, export spans, and sample traces.
---

In a system of several services, the W3C `traceparent` header carries the
trace of a request from one service to the next. `Air.trace` makes an Air
service take part. When a request has a valid `traceparent`, Air continues
that trace. When it has none, Air starts a new trace. After each request,
Air gives one span to an exporter that you choose.

## Add tracing to an app

To add tracing, put `Air.trace` in `Air.use`, inside `Air.request_id` and
outside `Air.log`:

```python
def app(req: Air.Request()) -> IO(Air.Response()):
  Air.use([
    Air.request_id,
    Air.trace(Air.Trace.print),
    Air.log
  ], base)(req)
```

With this order, each log line gets a `trace_id` field. You can then join
the log with the traces of the other services.

## Read the trace in a handler

`Air.trace` puts the ids in request locals:

| Request local | Value |
| --- | --- |
| `trace_id` | 32 hex characters: the caller's trace id, or a new random one |
| `span_id` | 16 random hex characters: the span of this request |
| `parent_id` | The span id of the caller, or `""` for a new trace |
| `trace_flags` | `01` when sampled, `00` when not |
| `traceparent` | The value to send to a service that you call |
| `tracestate` | The `tracestate` header of the caller, with no change |

## Pass the trace to another service

When a handler calls another service, send the `traceparent` request
local as the `traceparent` header of that request:

```python
Air.Request.local(req, "traceparent")
```

The next service then continues the trace under the span of this request.

## Send a valid traceparent

A valid value looks like this:

```text
00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
```

It has four parts: the version, the trace id, the span id of the caller,
and the flags. The hex digits must be lowercase, and neither id can be all
zeros. The version `ff` is not valid. For a version after `00`, Air reads
the first four parts only. Air starts a new trace for any other value, the
same as for a request with no header.

## Export spans

After the response is ready, `Air.trace` gives one span to the exporter.
`Air.Trace.print` prints each span as one JSON line on stdout, with the
OpenTelemetry names for HTTP attributes:

```json
{"trace_id":"4bf92f3577b34da6a3ce929d0e0e4736","span_id":"a1b2c3d4e5f60718","parent_span_id":"00f067aa0ba902b7","name":"GET /users/:id","start_time_unix_ms":1790000000000,"duration_ms":3,"http.request.method":"GET","http.route":"/users/:id","url.path":"/users/7","http.response.status_code":200}
```

An OpenTelemetry Collector can read these lines from the log, for example
with the filelog receiver. `Air.Trace.drop` exports nothing, but Air still
reads and passes on the ids.

To send spans somewhere else, write your own exporter: any def of type
`Air.Span() -> IO(Unit)`. Read the fields of a span with
`Air.Span.trace_id(s)`, `Air.Span.name(s)`, and the other accessors. To
record your own work, make a span with `Air.Span.new` and give it to the
same exporter. See the
[Observability reference](/docs/reference/observability#spans).

## Sample traces

A continued trace uses the sampled flag of the caller. `Air.trace` samples
every new trace. To sample one new trace in 10, use
`Air.trace_sampled(10, exporter)`:

```python
Air.use([Air.request_id, Air.trace_sampled(10, Air.Trace.print), Air.log], base)
```

Air decides from the last eight hex digits of the trace id. So every
service that samples in this way makes the same choice for a trace.
Requests that Air does not sample still get ids and a `traceparent`, but
the exporter does not get their span.

## Know the cost

Air makes ids from the random source of the host. Each draw costs about
as much as a system call. To continue a trace takes two draws, for the
span id. To start a trace takes six: four for the trace id and two for
the span id. For the measured cost, see [Benchmarks](/docs/project/benchmarks).

Air cannot send spans over OTLP yet. See [Limitations](/docs/project/not-yet).
