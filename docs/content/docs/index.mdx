Air is a web framework for [Bend](https://bend-lang.com). It serves
HTTP/1.1 over TCP and gives you routing, middleware, and the parts that
most web apps need. You write the app in Bend, and Air runs it on a
server that you start from `main`.

Air is for developers who write services in Bend and want the same tools
that a Node or Python framework gives. Air runs behind a TLS proxy, such as
nginx or Caddy. Air does not do TLS itself.

## A complete app

This program serves one route with a path parameter:

```python title="main.bend"
import Base
import ./air.bend as Air

def greet(req: Air.Request()) -> IO(Air.Response()):
  IO.pure(Air.Response(), Air.Response.text("hi " ++ Air.Request.param(req, "name")))

def routes() -> List<Air.Route()>:
  [Air.Route.get("/hello/:name", greet)]

def app(req: Air.Request()) -> IO(Air.Response()):
  Air.dispatch(routes(), req)

def main() -> IO(Unit):
  Air.serve(~app, 8080)
```

To run it, put `main.bend` next to `air.bend` and start it:

```bash
bend main.bend
curl localhost:8080/hello/world
```
